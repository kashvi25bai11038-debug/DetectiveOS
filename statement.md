# Project Statement — Detective OS

## Problem Statement
Most introductory crime-management demos only store records. They do not provide a structured workflow for connecting evidence, statements and timeline events. Detective OS addresses this by providing a fictional investigation environment with an explainable rule-based reasoning engine.

## Scope
The system covers fictional case management, suspect/witness records, evidence collection, interviews, timeline reconstruction, concurrent analysis, suspicion scoring, database persistence and report generation. It intentionally does not attempt real forensic analysis.

## Target Users
- Students demonstrating Java programming concepts
- Faculty evaluating object-oriented, database and concurrency concepts
- Users interacting with a fictional detective simulation

## High-Level Features
1. Authentication
2. Case management
3. Evidence locker
4. Suspect intelligence
5. Interviews and statements
6. Timeline reconstruction
7. Explainable reasoning
8. Concurrent analysis
9. JDBC analytics
10. Report generation
